# Especificaciones del MVP

Describen comportamiento objetivo y aceptación del P0. El [PRD](../exec-plans/GALCOA-PRD-v1.4.md) conserva la autoridad de producto; estas specs no prueban implementación ni cierran decisiones operativas por estar redactadas.

| Spec | Alcance |
| --- | --- |
| [Fuentes e IA](sources-and-ai.md) | Ingesta, procedencia, redacción, contraste, streaming y errores |
| [Revisión y confirmaciones](review-confirmation.md) | Snapshot común, participantes, decisiones y continuidad de versiones |
| [Capacidades públicas](public-capabilities.md) | Tokens, reemisión, privacidad, abuso y accesos públicos separados |
| [Entrega frontend](frontend-delivery.md) | Props, estados, allowlists y aceptación de las cinco entregas delegables |
| [Validación y release](release-validation.md) | Matriz PRD, niveles de prueba, evaluación y gates de entrega |

Los registros MVP-010…013 distinguen propuestas de parámetros definitivos. Al ejecutar F1 se registra la elección con fundamento y evidencia, sin ampliar P0 ni modificar el modelo/proveedor acordado por iniciativa local.
